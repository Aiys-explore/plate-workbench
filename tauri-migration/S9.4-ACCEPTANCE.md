# Plate 0.5.0-s9.4 Windows 补充验收

[S9.5 两跳激活、活力热力与记忆提案收口验收](S9.5-ACCEPTANCE.md)

2026-11-19 在已有 WebView2 的 Windows x64 主机上，从 S9.3 Release 下载并核对安装包，再用 S9.3 和 S9.4 安装包内的程序分别运行隔离的合成工作区。鼠标输入由 Playwright 发送至该程序的 WebView2，截图人工核对了连线端点和卡片文字。

| 项目 | 结果 |
| --- | --- |
| 闪念捕获后的探针连线 | S9.3 捕获闪念后能画出连线，但从 89% 放大到 109% 时，连线末端停在旧坐标，偏离目标卡片 25.73 CSS 像素。S9.4 在短暂预览期间更新端点。相同操作下，两端误差均小于 0.01 CSS 像素，连线结束后预览和高亮自动消失。[修复前](evidence/field-s9.4/s93-probe-zoom.png) · [修复后](evidence/field-s9.4/capture-probe-zoom.png) |
| 休眠星尘的鼠标悬停 | S9.3 和 S9.4 均通过。开启活力热力后，休眠卡片显示为点。鼠标移入后，在没有键盘焦点的情况下显示完整卡片，标题和摘要可见。移出后恢复为点。[收起](evidence/field-s9.4/dormant-collapsed.png) · [悬停](evidence/field-s9.4/dormant-hover.png) |

TypeScript 检查、Vite 生产构建、Rust 5 项测试和 Windows x64 NSIS 打包通过。最终 NSIS 内嵌 EXE 的 S9 回归 14 组和 S8 Agent 合成回归 10 组通过。真实 Agent 账号验收见 S9.2 和 S9.3 记录。[S9 回归](evidence/field-s9.4/brain-results.json) · [S8 回归](evidence/field-s9.4/agent-results.json) · [S9.2 报告](S9.2-ACCEPTANCE.md) · [S9.3 报告](S9.3-ACCEPTANCE.md)
