# Plate 0.3.0-s7.1

本分支包含 S7 审计修复 P1-1～P1-5、P2-1～P2-3，以及 Windows 启动和 Agent 配置修复。审阅基线为 `333800315cace3d9ed7d8f2523814f9bee87d253`。

## 使用

- Windows 版按图形程序构建。从开始菜单或安装目录打开 Plate。
- 从顶栏进入「Agent 设置」，可设默认 Agent 或选「每次选择」。笔记的任务行也可以通过「选择 Agent」指定本次目标。
- Codex、Claude Code、OpenCode 沿用各自本机 CLI 的登录或模型设置。DeepSeek Harness 后台进程使用 API Key，可在 Plate 设置中录入，也可从运行环境继承。Plate 用 Windows DPAPI 按当前用户加密保存密钥，只向前端返回配置状态。 [DeepSeek headless 说明](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/bundle/headless/README.zh.md)
