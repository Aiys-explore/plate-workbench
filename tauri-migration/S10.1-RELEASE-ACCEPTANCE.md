## 构建、校验与计划比对

- `cargo check --locked`、`cargo test --locked`（15 项）、`npm run typecheck`、`npm run build` 及 Windows M1–M4 冒烟通过。最终签名包的提取程序另通过 `checks/s10-release-ui-windows.mjs --packaged`。
- 匿名重新下载 EXE、SIG 与校验文件，SHA-256 与待发布包一致。Tauri 更新签名绑定 `0.6.0-s10.1`，篡改包校验失败。安装器 Windows Authenticode 状态为 `NotSigned`。安装包 SHA-256 为 `B79281C93C18DCEFD0B75B41B51895A43A3A9F114C07231D472D6289D5473241`。
- 隔离运行发布版 S10.0，实际通过 Tauri 更新插件发现 S10.1，下载并验签 6,165,424 字节。S10.1 在同一通道返回已是当前版本。该验证停在下载验签，日用安装未执行升级。[更新通道验收](evidence/s10.1-release/updater-verification.json)
- 原计划 §3.2、§3.5–3.8 和 M2–M4 的数据、授权与审阅行为延续，组合挂载未改 Rust 权限判定和 Tauri 调用。视觉修订版 §5.3–5.6 的图标、复合输入岛和悬浮交互延续。按本次要求，模型菜单从输入岛上方定位改为锚定模型按钮，其他面板沿用输入岛上方定位。[S10 原计划](plans/s10_workbench_harness_plan.md) · [S10 视觉修订版](plans/s10_workbench_harness_plan_1.md)
