# Plate Phase S7 修复计划

基线为 `checkpoint/tauri-s6` 的 `12e62fb`。从 Git 快照导出到本目录的 `source/`，按下列顺序修改并验收。

| 阶段 | 实施决定 | 验收 |
| --- | --- | --- |
| S7-1 Agent 运行 | Windows 以挂起状态启动 Agent，将其加入本次运行独有的 Job Object 后再继续。取消、超时和应用退出清理该进程树。Codex、Claude、DeepSeek 通过标准输入接收完整 UTF-8 文本。增加 DeepSeek 桌面版 CLI 的已知安装位置，不强制提高 Agent 权限。 | Windows 合成进程树验证停止、超时、正常收尾，保留无关进程。原任务和多行追问含中文、换行和 shell 符号，逐字节核对接收内容。用合成安装目录验 DeepSeek 发现。真实客户端另列结果。 |
| S7-2 可用入口 | 侧栏和编辑器通过同一确认逻辑删除笔记，创建项目走现有 Rust 接口。接通 Agent 发现、系统目录选择和受限外链打开。暂未迁移的界面入口按能力隐藏。 | 从两个界面入口删除合成笔记，校验取消和版本冲突。创建项目并新建所属笔记。检查已隐藏入口、目录选择取消和允许/禁用的链接协议。 |
| S7-3 草稿与审阅 | 任务文字变更纳入现有草稿和修订检查，先写入成功再推进任务。收集任务下的缩进内容，跳过代码，保留完整受限输出。追问结构按任务 ID 更新并保留焦点。 | 未保存内容分派与采纳后可继续保存。外部写入造成冲突时保留草稿并阻断分派。验代码围栏、多行追问、超过 40 行的结果和其他任务更新时的输入焦点。 |
| S7-4 关系图 | 坐标与画布范围随派生节点扩展。父笔记记录对子笔记的稳定 ID 引用，兼容旧链接与上下游箭头语义。 | 连续派生至少六层，坐标不重叠，重启保留。重命名前后同一对节点仍关联，父笔记可跳到子笔记。 |
| S7-5 清理和打包 | 从 S7 候选移除已由 Tauri 替代且构建不再引用的 Electron 主进程、预加载和重复 Cargo 文件。单独打试用包。 | 类型检查、Vite 构建、Rust 测试和 Windows 独立候选验收；留存安装器与哈希。 |

合并 GitHub 默认分支和目录提升是审计报告的后续建议，本轮交付独立 S7 候选。
