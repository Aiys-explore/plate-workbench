# Plate 0.5.0-s9.3 Windows 验收

## 编辑器修复

- 多行任务的正文和操作按钮各有可换行的空间。窄抽屉内，正文按原有顺序向下排，长标记可在列内换行。
- 采纳后的回执按 Markdown 引用原有换行显示。已有多行引用采用同一渲染规则。
- 笔记标题在独立标题栏编辑。新建及固化笔记使用已有标题元数据格式。旧笔记首行的 `# 标题` 在编辑器中作为标题读取，改名时转换为元数据。正文里的一级章节保留，正文原文模式也独立于标题。
